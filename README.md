# 议猫社：社区类微信小程序

这是一个基于微信原生小程序和微信云开发完成的毕业设计项目。项目名称为“议猫社”，面向社区场景提供猫咪相关的信息浏览、内容发布和互动功能。

仓库中的源码和流程图均为项目的一部分，适合作为微信小程序、云开发和社区类产品的学习参考。

## 功能

- 首页信息流和公告展示
- 猫咪、猫粮、繁育、医疗等内容模块
- 发布图文和视频内容
- 浏览详情、评论、点赞和取消点赞
- 内容举报和意见建议
- 个人发布、个人点赞和个人资料
- 微信云开发登录、云数据库、云存储和云函数

## 技术栈

- 微信原生小程序：JavaScript、WXML、WXSS、JSON
- 微信云开发：云函数、云数据库、云存储
- 数据库集合：`Users`、`Publishs`、`Likes`、`Comments`、`Reports`、`Suggests`、`Publicitys`

## 本地运行

### 1. 准备环境

安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，并准备一个已经开通云开发能力的微信小程序 AppID。

### 2. 导入项目

1. 克隆仓库。
2. 在微信开发者工具中导入仓库下的 `YiMaoShe` 目录。
3. 将 `YiMaoShe/project.config.json` 中的 `appid` 替换为你自己的 AppID。
4. 在 `YiMaoShe/miniprogram/envList.js` 中配置你自己的云环境 ID。

仓库中的 AppID 和云环境 ID 是原项目配置，不能保证仍然可用，也不代表当前项目提供可直接访问的线上服务。

### 3. 配置云开发

1. 在微信开发者工具中开通云开发并选择对应环境。
2. 根据“流程图/数据库结构.vsdx”和代码中的集合名称创建数据库集合。
3. 将 `YiMaoShe/cloudfunctions/` 下的云函数上传并部署到云端。
4. 按需要配置数据库权限和云存储权限。
5. 编译并预览小程序。
